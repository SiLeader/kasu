# Implementation Status

English | [日本語](implementation-status_ja.md)

All of `docs/plan` is in scope for implementation. This file records the current state and remaining work;
it does not shrink the original plan or its completion criteria.

The [plan mapping](plan-audit.json) records the hashes of the original six documents and the implementation locations and verification records for 36 items.
`implemented` indicates where the implementation lives; it does not mean every external acceptance test has been rerun on the current build.
See the linked records for the scope and runtime sources of each external test.

Following the user's instruction that "anything requiring security verification may be skipped for now",
OIDC and a shared cache across different permission scopes are left as unimplemented, deferred items.
Fuzz campaigns, dependency vulnerability assessment, and third-party security review are also unverified.
PAT / ACL and ordinary malformed-input regression tests are implemented, but they do not represent security approval.

The final regression run on 2026-10-26 passed 214 tests across the whole workspace, all targets, and all features; 21 were excluded from normal runs because they need
external fixtures / services, privileged environments, or child-process fixtures; and 11 Criterion smoke tests passed.
fmt / Clippy (warnings as errors) / actionlint / cargo-deny bans, licenses, and sources also pass.
The [run conditions, logs, and source hashes](verification/plan-regression/summary.json) are stored.
For individual runs and scope of excluded tests, see this record and each milestone's acceptance record.

Immutable records are stored only with put-if-absent; only ref updates and log appends are transactional.
Native Changeset creation does not accept GitProvenance. The import side verifies raw Git objects and
connectivity before storing. The import command initializes a tracing subscriber.
Prometheus metrics for cache / daemon / the authoritative server, OTLP trace export, and W3C context propagation are implemented.
Evaluating a collector in real operation and linking traces across durable webhooks are remaining work.
